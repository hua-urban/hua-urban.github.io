# 工業送風設備展示網格

由使用者提供的三份 STEP 模型在本機轉製：方框排風扇、輪架式移動坦克扇、側掛壁扇。保留護網、輪架、百葉、支架等固定部件，僅葉片與轉子組轉動。高密度護網適度簡化，保留輪廓。

三款各有 JSON 描述及二進位幾何，以毫米儲存；Y 軸朝上，正面為 +Z。原始 STEP、原始零件識別資訊及 CAD 轉檔環境未放上公開網站。

網站配置為產品與服務應用示意，非實際廠房還原、施工圖或風場模擬。模型權利依原權利人規範，非 Three.js MIT 授權範圍。
