# 晴天立扇桌網頁模型

依使用者提供的 STEP 工程模型轉製，供 E 組產業島展示。保留六片扇葉、橘色端翼、支柱、桌面與八個座位；隱藏的馬達內部及小型緊固件省略。保留工程模型原有配色。

網頁使用 33,255 個三角形、9 個材質群組，二進位幾何約 1.30 MB。原始 STEP 不納入公開網站。尺寸以毫米儲存，Y 軸朝上；旋轉組依 metadata 的 pivot 與 axis 運作，桌面與座椅固定。

轉檔工具：occt-import-js / Open CASCADE 與 meshoptimizer；僅轉檔時使用，網站不下載 CAD 轉檔執行環境。模型權利依原權利人規範，非 Three.js 的 MIT 授權範圍。
