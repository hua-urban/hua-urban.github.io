# A 組｜地主改建整合鏈：內容企劃

依 2026-09-03、2026-10-01、2026-10-15 三份組聚資料表整理；更新：2026-11-05。

## 定位

A 組面向考慮改建的社區地主與協作者，聚焦地主整合、權利資料、估價、建築規劃、契約、資金、工程材料與改建前後的使用交接。網站以「受眾 → 問題 → 專業協調 → 可留下的資料 → 下一位夥伴 → 需求提問」呈現協作入口，不代替任何個案專業判斷，也不把分享、名冊或單一進度寫成團隊成果。

本組主要內容是社區改建的整合與接棒流程，不以出租收益或投資現金流作為主軸。討論房屋出租或老屋經營時，可延伸參考 B 組；空間規劃、材料及工程議題可延伸參考 D 組。跨組連結是參考入口，不預設適用性、合作或服務承諾。

## 八個主題

### 社區地主整合與共識準備

先整理社區關心的事，讓下一次討論有共同起點。

- 對象：正在討論改建方向的住戶、地主代表，以及需要整理社區問題與對話節點的協作者。
- 問題：社區目標、住戶疑問與手上資料散落在不同對話中，容易反覆說明，也不容易判斷下一步要找誰。
- 介入：彙整共同關心的議題、已掌握資料與未決問題，再依需求邀請建築、估價、地政、法律或工程專業參與。這是協調與需求整理，不代表個案已取得共識或達成改建結果。
- 留下的資料：社區需求摘要、待確認問題、資料準備清單，以及下一次對話的主責與接續事項。
- 依 2026-10-15 資料表所列相關專業席位：莊大永、包育翎（地主召集／自主更新推動）；陳昭男（都更土地開發）。實際分工與服務範圍另行確認。

需求提問：社區目前最想先釐清什麼？已有什麼文件和疑問？下一次討論需要哪些專業參與？

### 土地、建物與權利資料整理

把現有資料與疑問分開，交給合適專業確認。

- 對象：希望開始討論改建，卻還在整理土地、建物或既有使用資料的地主與社區代表。
- 問題：資料版本、權利關係與住戶掌握程度不一，讓討論停在「還缺什麼」或「該問誰」。
- 介入：列出已有資料、來源與待釐清問題，再依問題轉介地政士或律師確認。網站只協助整理問題，不判讀產權、不代替法律意見，也不推定特定程序或門檻。
- 留下的資料：資料索引、待確認事項與適合接續的專業類型；不含個案權利結論。
- 依 2026-10-15 資料表所列相關專業席位：施宜妏（金融業法務顧問）；吳翊辰（地政士）。法律判斷與登記事項須由相關專業依個案確認。

需求提問：目前有哪些土地、建物或既有約定資料？哪些內容已確認、哪些需專業解釋？接下來應由哪類專業查看哪些文件？

### 更新方案與估價討論

先對齊比較基礎，再討論不同方案的條件。

- 對象：需要了解估價如何支援改建討論，或希望把不同方案放在共同基礎上比較的地主與社區代表。
- 問題：用途、範圍、時點與方案假設沒有說清楚時，數字容易被誤讀，也難以提出有用的追問。
- 介入：整理估價目的、可用資料與待比較的情境，再由估價專業說明採用範圍與假設。網站不提供個案估值、分配結論、收益預估或結果保證。
- 留下的資料：估價需求摘要、待補資料及供專業確認的方案比較問題。
- 依 2026-10-15 資料表所列相關專業席位：張瑜晏（不動產估價與鑑定）；陳昭男（都更土地開發）。估價範圍與結果由專業依委託內容確認。

需求提問：估價或比較要協助回答什麼？方案、資料時點與重要假設有哪些尚未對齊？哪些結論需要估價專業進一步說明？

### 建築規劃與空間方案

從住戶需求出發，整理值得進一步討論的空間條件。

- 對象：已有初步改建想法，想將社區需求轉成建築與空間討論題目的地主與協作者。
- 問題：住戶期待、基地條件、空間使用與工程限制尚未放在一起討論，容易太早聚焦在單一方案。
- 介入：列出使用需求、已知現況與希望比較的方向，再邀建築、室內設計或工程顧問確認需要進一步調查的事項。規劃內容、可行性與後續程序都需由相關專業依個案確認。
- 留下的資料：空間需求摘要、方案討論基礎與需由現場或專業補充的問題。
- 依 2026-10-15 資料表所列相關專業席位：柳慧燕（危老都更推動建築師）；諸紀平（住宅室內設計裝修）；張怡蘋（工程顧問）。個案規劃與承接範圍另行確認。

需求提問：社區希望改善哪些使用需求？有哪些現況、尺度或時程仍需現場確認？目前適合先比較方向，還是先補足基地資料？

### 合建、委託與合作契約討論

先列出需要談清楚的角色與條款，再請法律專業檢視。

- 對象：正準備討論合建、委託或其他改建合作方式，需要釐清文件與約定問題的地主及社區代表。
- 問題：角色、責任、交付內容與待確認條款若沒有列清楚，各方難以對照文件提出具體問題。
- 介入：整理契約草案、往來文件與各方疑問，交由律師依文件和個案提供法律意見。這是一般協調說明，不判讀條款、不提供法律或投資建議，也不宣稱可達成特定結果。
- 留下的資料：文件清單、待討論條款與供律師檢視的問題摘要。
- 依 2026-10-15 資料表所列相關專業席位：施宜妏（金融業法務顧問）。契約法律意見由律師依文件與個案提供。

需求提問：目前正在討論哪一種合作文件或約定？哪些責任、期限或交付事項還不清楚？有哪些資料應先交由律師閱讀？

### 改建資金與財務條件整理

把時程、費用與資金問題整理清楚，再找對應專業討論。

- 對象：需要先整理改建相關資金問題、貸款條件或財務資料的地主與社區代表。
- 問題：不同階段的費用、時間與資金來源尚未區分，容易把需要確認的問題混在一起。
- 介入：整理目前已知費用項目、時間安排與待問條件，再視需要轉介金融或財務專業。此內容不構成財務、投資或授信建議，不預測核貸、收益或回收結果。
- 留下的資料：資金議題清單、待補資料與應由金融專業確認的問題。
- 依 2026-10-15 資料表所列相關專業席位：陳秒螢（房屋貸款）；黃郁婷（金融業財務）；林媜媁（資通訊業財務分析師）。不構成財務或授信建議。

需求提問：目前要釐清的是資金來源、貸款條件，還是支出時程？有哪些費用資料已知？哪些問題需交給金融或財務專業個別評估？

### 營建、材料與施工協調

將設計、材料與現場限制，提早放進工程討論。

- 對象：已進入方案或工程討論，需要整理施工、材料與現場問題的地主代表、設計及工程夥伴。
- 問題：設計需求、工序、材料選擇、進場限制與預算問題若分開處理，容易在後續協調時才發現落差。
- 介入：確認設計資料、工程範圍與現場條件，再依需求邀請工程、材料或營造相關專業討論。網站不承諾固定承攬團隊、工程價格、工期或施工成果。
- 留下的資料：工程問題摘要、材料與工法待確認事項，以及下一個現場協調窗口。
- 依 2026-10-15 資料表所列相關專業席位：張怡蘋（工程顧問）；林中群（鋼結構防蝕工程）；蔡岱達（磁磚經銷）。實際施工團隊與範圍逐案確認。

需求提問：目前有哪些圖面、工程範圍或現場資料？材料、工法、進場或施工順序有哪些待確認？下一步需要哪類專業？

### 改建前使用與改建期間交接

把目前如何使用、由誰接續與尚待確認事項放在一起。

- 對象：評估改建時，也需要整理現有房屋使用、日常維護或後續交接問題的地主與住戶代表。
- 問題：改建討論期間的使用需求、時間安排、維護責任與交接窗口若未整理，容易留下資訊缺口。
- 介入：記錄房屋用途、相關角色、時程與待處理事項，再安排對應的專業對話。若涉及出租或老屋經營，可參考 B 組老屋現金流協作島；若涉及空間規劃或建材工程，可參考 D 組商用空間協作島。跨組內容只是參考入口，不代表合作或服務承諾，適用性須另行確認。
- 留下的資料：使用與時程摘要、交接責任清單，以及需要由法律、工程或使用規劃專業確認的問題。
- 依 2026-10-15 資料表所列相關專業席位：莊大永、包育翎（地主召集／自主更新推動）；柳慧燕（危老都更推動建築師）。跨組窗口與服務範圍另行確認。

需求提問：房屋目前如何使用、預計何時需要調整？使用、維護與聯絡責任由誰接續？哪些使用或交接條件仍需其他專業確認？

## 協作情境

情境是依資料整理的接棒構想，不代表案件成果、固定流程或任何夥伴已承諾承接。

### 社區想啟動改建

社區對改建有初步討論，希望知道下一輪對話可以先準備什麼。

1. 整理共同關心的事：記錄社區主要疑問、希望討論的方向與目前已掌握的資料。
2. 盤點資料與待確認點：整理土地、建物及既有約定資料，再把需要解釋的問題交由相應專業確認。
3. 確認方案比較問題：說明希望比較什麼、有哪些資料和假設，估價範圍由估價專業確認。
4. 邀請建築專業討論：將社區需求轉成空間與規劃問題，保留現場及個案評估。

### 整合卡住怎麼接棒

當社區對話反覆或無法往下安排，可先分清楚是資料、權利、契約或接續責任的問題。

1. 描述目前卡點：把已討論事項、不同疑問與需要決定的下一步分開記錄。
2. 整理相關文件：標示哪些資料已具備、哪些待補，並由地政或法律專業確認需看的內容。
3. 列出契約問題：將有疑問的條款與角色責任整理給律師檢視，不以網站內容代替法律意見。
4. 指定後續接棒事項：確認下一位窗口、需要補充的資料與預計回覆節點，方便社區追蹤。

### 改建前房屋如何使用

改建評估期間，住戶也可能需要整理房屋現況、暫時使用與交接問題。出租或老屋經營議題可參考 B 組；空間規劃、建材與工程議題可參考 D 組。這些內容是延伸閱讀入口，不代表合作承諾或特定服務可用。

1. 盤點現況與時間：記錄房屋目前用途、需要調整的時間點及尚待處理的事項。
2. 確認既有使用約定：整理相關文件與疑問，交由法律或地政專業依個案確認。
3. 整理必要維護問題：區分日常維護與工程改善的疑問，材料、工法及現場範圍另行確認。
4. 安排社區溝通與交接：確認需要通知的對象、負責窗口及下一步資料，讓使用安排接回整體討論。
