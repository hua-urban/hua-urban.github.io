隱私權政策

適用工具：華都更週會簡報整合。管理與聯絡單位：華都更資訊組。本政策只描述此簡報整合流程，不代替華都更其他網站、表單或 LINE 服務的政策。

應用說明

一、存取哪些資料

經分會指定帳號同意後，工具存取指定來源中的檔案名稱、格式、修改時間、權限與位置等中繼資料，以及用於週會的 Google 簡報、PPTX、PDF 和圖片內容；素材可能含會員姓名、照片、專業及簡報文字。工具也讀取授權帳號電子郵件，用於核對分會執行身分。

Drive 授權範圍允許存取授權帳號可存取的檔案，並非單一檔案權限；實際程式僅處理設定的週會來源、總簡報、備份及成果位置。不要求讀取 Gmail 郵件、通訊錄、密碼或驗證碼。

二、如何使用

資料只用於辨識週會素材、建立備份、整合會員及教育投影片、匯出與驗證 PDF、清理本次建立的暫存檔，以及維運錯誤處理。總簡報更新只針對設定的段落，其餘內容保留。整合流程不出售 Google 使用者資料，不用於廣告，也不將資料用於 AI 模型訓練。

三、處理位置與接收者

檔案在 Google Drive／Google 簡報及 GitHub Actions 執行環境中處理；原生投影片整合由私有 Google Apps Script 執行。成果、備份存於資訊組指定的 Google Drive 位置，不由本流程新增公開分享。檔案沿用既有的擁有者及分享權限。

必要的失敗資訊、來源連結或檔案識別資訊，依既有維運設定送到資訊組的 LINE 通知端及啟用時的 Telegram 通知端；不向 AI 朋友或公眾傳送素材。本政策不宣稱所有通知收件人皆已完成交接，資訊組須核對通知端的綁定與設定。

四、保存與保護

OAuth 更新權杖及用戶端憑證保存於私有專案的 GitHub 加密 Secrets；執行時在記憶體及必要的暫存設定中使用，不放入公開程式庫或本說明網站。Drive、總簡報、備份及 PDF 的存續由資訊組的檔案管理決定，不承諾自動刪除所有歷史成果。

本流程建立的轉檔或圖片暫存檔，結束時嘗試移到 Drive 垃圾桶；若清理失敗，保留錯誤供人工處理。GitHub 執行環境結束後由平台回收；整合驗證附件目前保留 30 天，其他執行紀錄依專案及平台的保存設定。執行紀錄可能含檔名、檔案識別資訊、頁數及錯誤，不應對外公開。

五、停止授權與資料處理

帳號持有人可在 Google 帳號的第三方應用存取設定撤銷授權；資訊組可停用 GitHub 排程並刪除相關 Secret。撤銷授權會阻止後續存取，但不會自動刪除先前的總簡報、成果或備份。若需要查詢、修正或刪除資料，請聯絡資訊組，由有權限的管理人員處理並確認範圍。

六、Google 使用者資料規範

本工具對 Google API 資料的使用與轉移須遵守 Google API Services User Data Policy，包含 Limited Use 要求。用途或資料處理方式有實質變動時，應更新政策並在需要時重新取得授權。
