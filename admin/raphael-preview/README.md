# 拉斐爾寫實動畫獨立預覽

依使用者最新要求改為寫實成年守護者。從 Apple「照片」2025 年 4 月 9 日找到正面、斜側面、側面、背面及羽翼近照；以使用者實際雕像的正面與側面作主要參考，保留原羽翼、權杖與人物的相對配置。生成圖像為依照片重新製作的寫實視覺，並非照片掃描的 3D 模型。

使用者先要求強化權杖與羽翼氣勢，之後明確更正為原雕像比例；本次採最後指示，使用 `raphael-faithful-v3.webp`。不發布過度放大權杖的中間版本、原始相簿照片或家中背景。

維持獨立預覽，尚未掛入管理中心或案件載入畫面。`index.html` 搭配一張約 168 KiB 的透明 WebP，SVG 重用同一圖像做羽翼微動、CSS 光暈與細微金屬流光。沒有影片、外部字型、動畫套件、追蹤程式或後端 API。日光／夜光、放大／入口尺寸、暫停／播放均可切換；尊重減少動態效果設定。圖片以 preload 優先載入，重複圖層共用同一 URL。

本機檢查：內嵌 JavaScript 語法；檔案與素材路徑；日光／夜光、入口尺寸、暫停／播放；實際頁面截圖。原始高解析生成素材及參考照片只保留於本機工作成果資料夾。

正式獨立網址：`https://hua-urban.com/admin/raphael-preview/`。回復時還原此資料夾至 PR #54 的版本，不影響既有服務入口、登入或案件資料。
