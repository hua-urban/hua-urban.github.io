# 官網顯示內容的試算表管理

沿用華都更原有會員管理試算表，未變更檔案擁有者或共用權限。

| 分頁 | 可修改欄位 | 顯示位置 |
| --- | --- | --- |
| Groups | B 欄「鏈名」、D 欄「固定組聚時段」 | 官網首頁、產業鏈分組頁 |
| 網站內容設定 | B 欄「顯示內容」 | 首頁公告及「關於分會」標題、兩段介紹 |
| 服務連結 | 名稱、網址、說明、啟用 | 已接線的官網入口及管理中心服務卡片 |

修改後重新整理頁面即可讀取；不需重新部署。網站內容與連結頁只放預定公開的資料。公告標題、內文同時留白時，公告區塊不顯示。網址僅接受 HTTPS 或站內路徑。

Groups 的 A 欄組別代號應保留，C 欄組長由會員管理中心的「組長交接」產生。會員新增、退會、入會日與分組關係仍由中央會員管理流程處理，不以修改顯示設定增減會員。

活動行事曆與各服務原有報名表仍沿用既有來源；本次未把報名紀錄或 PALMS 統計搬到顯示設定中。

## 維護說明

同一華都更帳號 Apps Script 專案提供名冊與 `?action=siteContent` 唯讀端點。網站內容端點只回傳明確列入清單的設定代碼、服務代碼及組別顯示資料，不回傳會員正本、稽核紀錄或私人資料。前端以純文字顯示設定內容；格式不像 HTML 的字串也不作 HTML 執行。

中央會員儲存流程只更新 Groups 的 A/C 資料欄，不覆蓋 B/D。以組別代號對應列，不依賴固定列順序。空白組聚時間會保留空白，分組頁沿用「待補」顯示。
