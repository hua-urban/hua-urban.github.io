BNI Connect · 真實填表測試

把自己的 121 與引薦紀錄填進 Connect

建立你自己的 121 與引薦草稿。書籤小工具可單筆填入讓你核對，也可在你檢視清單並親自開始後，嘗試逐筆自動送出。

●
這是獨立測試站。所有欄位從空白開始。資料只在這台裝置的瀏覽器中，按「準備帶入」才儲存；本站不要求 BNI 密碼。只有你在 Connect 面板確認開始自動批次後，小工具才會按提交。

1. 建立自己的實際紀錄草稿

請用你自己的 BNI 帳號資料填寫。接收會員、分會和登入身分會由你在 Connect 最後核對。

會員編號只用於查已確認的姓名對照，不是 BNI Connect 身分驗證。

尚未準備草稿。先新增至少一筆紀錄。

查看已準備的 JSON

改動草稿後，請重新按「準備帶入」，BNI 面板才會讀到新版。你也可以用 JSON 貼上，避開瀏覽器的小視窗限制。

2. 在 BNI Connect 填入

  1. 在左邊填好資料，按 準備帶入。
  2. 把下方 填表書籤拖到瀏覽器書籤列。請在電腦版瀏覽器操作。
  3. 登入你自己的 BNI Connect，核對登入帳號，再點書籤。
  4. 讀取草稿後，可手動開表單，點「填入，停在提交前」逐欄核對；或按「檢視並自動送出草稿」，看完收件清單再親自開始批次。
正在建立填表書籤…

書籤可重複使用。點擊書籤只顯示填表面板；自動批次須在面板另行確認。若 Connect 沒有明確成功通知，面板只記「已操作提交，待核對」。

請注意：單筆模式中，收件會員與 121 邀請人須自行選。自動批次只在姓名與邀請人能唯一核對時繼續；遇到不明對象、重複或新確認訊息會停止。引薦的其他說明請在 Connect 手動補齊。BNI 若更新表單，欄位定位可能需要調整。
